# 第六回ポケポケ段位戦 組み合わせ・対戦表

各グループで総当りの対戦を行ってください。
各試合は2本先に取った方の勝ちです。

## 書き方

取った本数 - 取られた本数 勝敗
例

```
    2-1 ◯
```

自分の行が自分の点数勝敗となります。
