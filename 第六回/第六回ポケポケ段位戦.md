## ルール

ポケポケ段位戦では同じ段位の対戦相手と総当りで2本先取形式で試合を行うリーグ戦を行い、その結果を集計し、段位内の順位を決定します。(その結果によって入れ替え戦や昇格降格が決まります)
タイブレーカーは基本的に得失点が高い人、負け試合の勝ちが多い人、勝ち試合の負けが少ない人の順で決定します。

各マッチのルールは2本先取制で、試合ごとのデッキチェンジは自由です(この理由はこちらで管理することが難しいからです)

試合後ですが、kadokaをメンションして試合の結果と獲得本数を報告してください
テンプレは以下です。

``` text
@kadoka
あなたの名前 vs 相手の名前　取った本数-取られた本数　勝敗
```

## 段位の昇格降格について

各段位の1位は自動昇格 2位は昇格戦 下から2番目の人は降格戦 1番下の人は降格します
段位の数は人数によって決定します
